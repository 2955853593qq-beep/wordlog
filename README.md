# Wordlog · 个人英语词书

纯 HTML、CSS、JavaScript 网站，无需安装框架或执行构建。

保留添加单词、多义项、重复检测、词性快捷按钮、搜索、义项编辑、独立忘记历史、短暂撤销、经常忘记、可读词表复制、完整备份与恢复。
待辨析和相似单词功能已撤回。词书中的单词正常独立显示。

## 运行与部署

本地可在此文件夹运行 python -m http.server 8765，然后打开 http://localhost:8765。
部署时把以下六个文件一起上传到同一个目录，index.html 位于网站根目录：

- index.html
- styles.css
- app.js
- db.js
- pos-input.js
- backup.js

不需要上传 README.md 或任何 work 测试文件。

## 清空试用数据

打开「我的词书」，展开「数据管理 · 备份与恢复」，点击「清空词书」并确认。
清空只作用于当前浏览器、当前网址。清空后如需找回，只能恢复此前保存的完整备份。
网站不会自动删除数据，也没有内置示例单词。

## 存储兼容

IndexedDB 数据库仍为 wordlog、版本 2，避免旧浏览器出现降级错误。
旧词组仓库仅为旧备份兼容保留，不再用于界面显示或自动添加词条。
完整备份与可读词表是两个独立功能。完整备份可以恢复全部持久化数据。
